# Contributing to CANmeleon Hardware

[English](#english) · [中文](#中文)

## English

1. Open a hardware Issue to describe the board or documentation change and its intended use.
2. For a design contribution, include editable source files, a schematic preview, a BOM, board revision and pin/clock/interface information. Identify the design tool and version needed to open the files.
3. State the applicable license and preserve third-party attribution. Submit material you have permission to publish.
4. Describe applicable firmware and host interfaces separately from the physical hardware.
5. Submit a pull request explaining the change and how to use the contributed files.

Use the [firmware issue tracker](https://github.com/CANmeleon/canmeleon-usb-can-firmware/issues) for firmware behavior and adaptation. Send commercial project documents to [len2slaw@foxmail.com](mailto:len2slaw@foxmail.com).

## 中文

1. 在硬件 Issue 中说明板卡或文档修改及预期用途。
2. 贡献设计时提供可编辑源文件、原理图预览、BOM、板卡修订，以及引脚、时钟和接口信息，并注明打开文件所需的设计工具及版本。
3. 说明适用许可证，保留第三方署名，提交有权公开的资料。
4. 将适用固件、电脑端接口与物理硬件分别说明。
5. 通过 Pull Request 说明修改内容及所提交文件的使用方式。

固件功能与适配需求请使用[固件问题入口](https://github.com/CANmeleon/canmeleon-usb-can-firmware/issues)。商业项目资料请发送至 [len2slaw@foxmail.com](mailto:len2slaw@foxmail.com)。
